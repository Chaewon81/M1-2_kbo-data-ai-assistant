# 8. 데이터 정제 계획

과제에서 반드시 결측치와 이상치를 확인하고 처리 기준을 설명해야 한다.

## 결측치

다음을 확인한다.

* 경기 날짜 누락
* 팀명 누락
* 상대팀 누락
* 점수 누락
* 경기 결과 누락

취소된 경기는 실제 완료 경기 데이터와 구분한다.

우천취소 등 실제 경기가 진행되지 않은 경우 분석 대상에서 제외할 수 있다.

처리 기준은 REPORT.md에 기록한다.

---

## 무승부

무승부는 이상치가 아니다.

정상적인 경기 결과로 유지한다.

```text
W = 승
L = 패
D = 무
```

승률 계산에서는 KBO 방식과 동일하게 승과 패를 기준으로 계산하는 방법을 검토한다.

예:

```python
win_rate = wins / (wins + losses)
```

실제 계산 기준은 KBO 공식 기록과 비교하여 검증한다.

---

## 이상치

점수 차이가 매우 큰 경기 등이 있더라도 자동으로 삭제하지 않는다.

야구 경기에서 실제 발생한 결과라면 정상 데이터일 가능성이 높다.

이상값을 발견하면:

1. 원본 KBO 기록 확인
2. 실제 경기 결과인지 검증
3. 실제 기록이면 유지
4. 데이터 오류일 경우 수정 또는 제외하고 이유 기록

# 11. 인사이트 작성 원칙

과제에서는 인사이트가 최소 3개 필요하다.

각 인사이트에는 반드시 **수치 또는 그래프 근거**가 있어야 한다.

아래 구조를 기본으로 사용한다.

### 관찰 Fact

실제 데이터에서 확인한 내용.

예:

> KIA의 2024년 6월 승률은 XX%였으며 7월에는 XX%로 변화하였다.

### 해석 Hypothesis

관찰 결과에 대한 가능한 설명.

예:

> 일정 구성이나 선수 상태 등의 영향을 받았을 가능성이 있다.

데이터만으로 원인을 확정하지 않는다.

### 추가 확인

필요하면 KBO 기록이나 기사 등 외부 자료를 추가로 조사한다.

---

# 12. 관찰과 해석 구분

중요한 과제 평가 항목이다.

잘못된 예:

> 7월에 주전 선수 부상 때문에 팀 성적이 떨어졌다.

데이터만으로는 원인을 증명할 수 없다.

올바른 방식:

### Fact

> 7월 승률이 6월보다 XX%p 감소했다.

### Hypothesis

> 선수 부상, 일정, 상대팀 구성 등의 영향을 받았을 가능성이 있다.

외부 근거를 확인한 경우 출처를 표시한다.

* 월별 집계 결과: `data/processed/monthly_summary.csv`에 시즌·월·팀별 경기 수·승·패·무·승률을 저장했다. 월별 합계를 다시 더한 값은 검증된 시즌별 집계와 일치했다.
* 월별 흐름 확인: 2023년 KIA는 6월 0.318 후 7월 0.688로 상승했고, 삼성은 6월 0.280으로 가장 낮았다. 2024년 KIA는 7~9월 0.682·0.609·0.684, 삼성은 8월 0.708을 기록했다. 2025년 KIA는 6월 0.682 후 7월 0.333·9월 0.316으로 하락했고, 삼성은 9월 0.611을 기록했다. 이는 데이터에서 확인한 사실이며 원인은 확정하지 않는다.
* 해석 주의: 3월과 10월은 시즌 시작·종료 시점이라 경기 수가 적을 수 있다. 예를 들어 2025년 10월은 KIA 3경기, 삼성 1경기이므로 해당 월 승률을 장기 흐름처럼 해석하지 않는다.
* Rolling 분석 방법: 같은 팀·같은 시즌의 경기를 날짜·게임 ID 순으로 정렬한 뒤, 현재 경기를 포함한 최근 10경기로 이동 승률을 계산했다. 무승부는 10경기 창에 포함하되 승률은 `승 / (승 + 패)`로 계산했다. 첫 9경기는 10경기 창이 완성되지 않아 빈값으로 두었다.
* Rolling 검증: `data/processed/rolling_win_rate.csv`는 분석용 경기와 같은 864행이다. 팀·시즌 6개 조합에서 첫 9행을 제외한 810행은 모두 10경기 승률을 갖는다.
* Rolling 흐름 확인: 2023년 KIA는 9월 6일 0.900까지 상승 후 9월 24일 0.100까지 하락했고, 삼성은 5월 9일 0.700 후 6월 23일 0.100을 기록했다. 2024년 KIA는 9월 14일 0.900, 삼성은 4월 17일 0.800을 기록했다. 2025년 KIA는 6월 26일 0.875 후 7월 26일 0.100, 삼성은 5월 31일 0.900을 기록했다. 이는 데이터 관찰 결과이며 성적 변동의 원인은 이 데이터만으로 확정하지 않는다.

# 26. Mission.md 기준 최종 요구사항 점검 (2026-09-18)

## 26.1 과제 목표를 쉽게 설명하기

이 과제의 목표는 **시간에 따라 변하는 야구 경기 데이터를 수집하고, 정리하고, 그래프로 확인한 뒤, 숫자에서 보이는 사실과 그 의미를 구분해 설명하는 것**이다.

이 프로젝트에서는 KIA와 삼성의 2023~2025년 정규시즌 경기를 시간 순서로 분석했다. 단순히 “어느 팀이 더 잘했다”라고 말하는 데서 끝나지 않고, 다음 과정을 수행했다.

1. **질문 만들기**: 시즌 성적 변화, 월별 성적 흐름, 주요 선수 기록 변화라는 질문 3개를 정했다.
2. **데이터 수집**: Python으로 KBO 공식 경기일정·결과를 월별로 수집했다.
3. **데이터 정제**: 미완료·취소 일정은 분석에서 제외하고, 완료 경기 864개 팀-경기 데이터 포인트를 만들었다.
4. **검증**: 표본 경기와 시즌 최종 승·패·무를 KBO 공식 기록과 비교했다.
5. **시계열 분석**: 시즌별·월별 승률을 집계하고, 최근 10경기 이동 승률로 짧은 기간의 흐름도 계산했다.
6. **시각화**: 연도별 승률, 월별 승률, 선수 비율 지표, 선수 누적 지표 그래프 4개를 만들었다.
7. **해석**: 그래프에서 확인한 수치(Fact)와 가능한 의미(Interpretation)를 구분해 인사이트 3개를 작성했다.

발표나 제출 때는 다음처럼 설명하면 된다.

> “KBO 공식 데이터를 Python으로 수집해 KIA와 삼성의 2023~2025년 성적 흐름을 분석했습니다. 완료된 경기만 사용하고 공식 기록과 대조해 데이터를 검증했습니다. 월별 집계와 최근 10경기 이동 승률을 적용해 시즌 전체 성적뿐 아니라 시즌 중 흐름을 확인했습니다. 그래프에서 확인되는 사실과 성적 변화의 원인에 대한 해석은 구분해서 작성했습니다.”

## 26.4 보너스 과제 선택지와 추천

보너스는 현재 프로젝트로 수행할 수 있다. 다만 기본 과제를 먼저 GitHub에 올린 뒤, 아래 중 **하나만** 선택하는 것을 추천한다.

### 추천: (B) 간단 예측 — 기준선 월별 승률 예측

현재 월별 데이터가 이미 있으므로 가장 자연스럽고 구현 부담이 작다.

1. 2023~2024년의 같은 월 승률 평균을 계산한다.
2. 그 값을 2025년 각 월의 “예측 승률”로 사용한다. (복잡한 AI 예측이 아니라 비교 기준선이다.)
3. 실제 2025년 승률과 예측값을 한 그래프에 표시한다.
4. 오차(MAE 등)를 계산하고, “과거 2개 시즌만 사용했으며 월별 경기 수가 달라 정확한 예측 모델은 아니다”라는 한계를 작성한다.

생성 파일 예시: `forecast.py`, `data/processed/monthly_forecast.csv`, `images/05_baseline_forecast.png`. 이 방식은 보너스의 “간단 예측 + 시각화 1개 이상 + 가정·한계 설명” 조건에 맞는다.

### 대안: 웹 대시보드

`dashboard.html`에서 팀과 시즌을 선택하면 월별 승률 그래프가 바뀌도록 만들 수 있다. 별도 유료 배포 없이 `python -m http.server`로 로컬 실행하고, 화면 캡처·필터 변경 시나리오·README 실행 방법을 제출하면 보너스 조건 (2) 또는 (3)에 맞출 수 있다. 다만 HTML·JavaScript를 추가로 익혀야 하므로, 현재 단계에서는 기준선 예측 보너스를 먼저 추천한다.

* [x] 예측의 가정과 한계를 REPORT에 기록했다.

### 사용한 예측 방법

복잡한 AI 예측 모델 대신 **같은 달의 과거 승·패를 합산한 승률**을 기준선 예측값으로 사용했다. 예를 들어 2025년 6월을 예측할 때는 2023년과 2024년 6월의 승·패를 합산해 승률을 계산한다. 이 방법은 단순하지만, “예측 모델이 과거 실제값과 얼마나 차이 나는가”를 확인할 수 있는 출발점이다.

### 2026년 기준선 승률 예측

| 팀 | 학습 데이터 | 예측 승률 | 의미 |
|---|---|---:|---|
| KIA | 2023~2025년 225승 199패 | 0.531 | 세 시즌 합산 승률을 기준선으로 사용 |
| 삼성 | 2023~2025년 213승 214패 | 0.499 | 세 시즌 합산 승률을 기준선으로 사용 |

이 값은 **2026년 실제 결과를 단정하는 예측이 아니다.** 선수 구성, 부상, 일정, 상대 전력처럼 현재 데이터에 없는 요인을 반영하지 못하고, 학습 기간도 3시즌으로 짧다. 따라서 향후 실제 2026년 결과 또는 더 많은 데이터를 얻었을 때 비교할 기준점으로 사용한다.
